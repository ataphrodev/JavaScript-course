# JavaScript course

My personal repository for learning JavaScript, following the course
**"JavaScript desde 0"** by [MoureDev](https://mouredev.pro).

## About

This repository contains the exercises, notes and my own katas I write while following the course.
Each lesson has its own file inside the `src/` folder, numbered in order.

## Project structure

```
javascript/
├── src/           # Source code: one file per lesson
├── docs/          # Course material (not tracked by git)
├── .editorconfig  # Editor settings (indentation, encoding...)
├── .gitignore     # Files and folders ignored by git
└── README.md      # This file
```

## How to run

You need [Node.js](https://nodejs.org) installed. Then, from the project root:

```bash
node src/<file>.js
# Example:
node src/03-beginner-exercises.js
```
